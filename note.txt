1. Déployer le VPS + Docker Compose (Nginx, React, Strapi, PostgreSQL) → accessible en HTTP sur l'IP, TEMPORAIREMENT
        │
2. Acheter le domaine .tn
        │
3. Pointer le DNS (enregistrement A) vers l'IP du VPS
        │
4. Attendre la propagation DNS (vérifiable avec `dig tonapp.tn` ou dnschecker.org)
        │
5. Lancer Certbot → il valide le domaine et génère le certificat HTTPS
        │
6. Nginx bascule en HTTPS (:443), redirection automatique HTTP → HTTPS
